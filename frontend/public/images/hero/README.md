# Imágenes — Hero / marca

Coloca aquí estos archivos (mismo nombre exacto, minúsculas):

| Archivo | Dónde se usa | Tamaño recomendado |
|---|---|---|
| `hero-principal.jpg` | Fondo de la portada (Hero) | 1920×1080 (horizontal) |
| `logo-umes.png` | Logo UMES (navbar, hero, footer, encabezado de la ficha impresa) | Cuadrado, fondo transparente, mín. 200×200 |
| `logo-isel.png` | Logo ISEL (navbar, hero, footer, encabezado de la ficha impresa) | Cuadrado, fondo transparente, mín. 200×200 |
| `favicon.png` | Ícono de la pestaña del navegador | 512×512 |

Mientras no subas el archivo, esa zona se ve como un recuadro punteado con el nombre esperado — no se ve "rota".
